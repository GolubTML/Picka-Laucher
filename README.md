# Picka Launcher

Launcher for patching and modding Terraria via [Picka](https://github.com/GolubTML/Picka.git)!

## All features in launcher:
- APK patching. It's easy and fast to use.
- Automatic APK sign and installation after patching.
- Mod list. You can see all mods from `/storage/emulated/0/Mods`. (Launcher will create this folder automatically)
- Mod creation. You can easily create basic mod in launcher.
- Mod profiles. You can see all information about mod (such as mod name, author, version and description) in one profile.
- Easy mod deletion from launcher.
- And launching Terraria from launcher.
    
## How to install and use
1. First, download the launcher from the `Releases` page.
2. Make sure you have Terraria APK on your phone.
3. Grant the required storage and installation permission.
4. Go to Patch screen.
5. Tap on button 'Select APK', and select your Terraria APK there.
6. After that, tap on 'Patch APK', and wait until installation popup.
7. Install patched APK, and you will have a patched APK!

## Requirements
- Android 11+
- ARM 64 architecture
- Terraria APK
